The Cua Spaces app checks for new versions but never downloads or installs
them. When a newer release exists, it says so and gives the command that
updates your checkout and rebuilds the app; the update itself is yours to run.
Everything is in **Settings, About**.

## How it works

The app checks when it starts and again every few hours. A found release
appears as **Update available** at the bottom of the sidebar, with the
version, a **What's new** link to the release notes and the rebuild
instruction; **Settings, About** shows the same. **Check Now** checks right
away, and **Last check** says when it last looked. Turn off **Automatically
check for updates** to only check by hand.

## Updating

Pull the repository and rebuild the app you run:

- Desktop app: `git pull && pnpm --dir apps/cua-spaces-desktop dist:mac`
  (use `dist:win` on Windows and `dist:linux` on Linux).
- Native macOS app: `git pull && apps/cua-spaces-macos/scripts/build-release.sh`.

## Channels

**Update to** picks which releases the check follows:

- **Stable**: releases.
- **Beta**: releases and prereleases, with new features sooner and rough
  edges.

Going back to Stable from a newer beta keeps the version you have until a
newer stable release is out.

## After updating

The first time the new build opens, it refreshes what Cua installed into
your AI agents, the way `cua agents update` does: the Cua skill folders and
the Cua MCP entries in Claude Code, Cursor and the other agents you set up.
A skill folder you edited is left as you left it. It also restarts the Cua
daemon when the app started it, so the daemon runs the new version too.

This happens without any window. If something fails, the app shows one
notice with what to run.
