This build installs from source. Clone the fork, check out `local-build`, and
run the source installer. Updates are explicit: pull the repository and
rebuild.

<Tabs items={['macOS', 'Windows (preview)', 'Linux']}>
  <Tab value="macOS">
    ```bash skip="host-install"
    git clone https://github.com/chriswritescode-dev/cua.git
    cd cua
    git checkout local-build
    scripts/install/install.sh
    ```

    The installer builds Cua Spaces with
    `apps/cua-spaces-macos/scripts/build-release.sh` and the `cua` CLI with
    cargo. macOS 26 or later.
  </Tab>
  <Tab value="Windows (preview)">
    <Callout type="warn">
      Cua Spaces for Windows is a preview. Expect rough edges and tell us what
      you hit.
    </Callout>

    ```powershell skip="host-install"
    git clone https://github.com/chriswritescode-dev/cua.git
    cd cua
    git checkout local-build
    powershell -ExecutionPolicy Bypass -File scripts\install\install.ps1
    ```

    The Windows source build has no app target yet: the installer builds the
    `cua` CLI and cua-spacesd. Build the app from
    `apps/cua-spaces-desktop` with `pnpm dist:win` if you need it.
  </Tab>
  <Tab value="Linux">
    ```bash skip="host-install"
    git clone https://github.com/chriswritescode-dev/cua.git
    cd cua
    git checkout local-build
    scripts/install/install.sh
    ```

    The Linux source build has no app target yet: the installer builds the
    `cua` CLI and cua-spacesd. Build the app from `apps/cua-spaces-desktop`
    with `pnpm dist:linux` if you need it.
  </Tab>
</Tabs>

At a console the installer shows a checklist first. Add `--cli-only`
(`-CliOnly` on Windows) to install the CLI alone.
